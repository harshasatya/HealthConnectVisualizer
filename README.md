# Health Connect Visualizer

This is an Android app that visualizes health and fitness data from Health Connect.

## Requirements

To build and run this project, you will need:

*   Java Development Kit (JDK) 11 or higher
*   Android SDK
*   Android Studio (recommended)

## Building the project

Once you have the required dependencies, you can build the project using the following command:

```bash
./gradlew assembleDebug
```

## Running the app

You can run the app on an Android device or emulator using Android Studio.
